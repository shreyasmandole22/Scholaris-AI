Inside the assistant

Scholaris answers from your course videos instead of guessing. Here is what runs behind each reply.

Answer model

Google Gemini (gemini-3.5-flash-lite) writes the reply. It is told to use only the retrieved course content, keep answers short, and cite the video and time for each point.

Embedding model

gemini-embedding-001 turns text into 768-number vectors. Course chunks are embedded as documents and your question is embedded as a query.

Retrieval (RAG)

Your question's vector is compared with all 1,467 transcript chunks using cosine similarity. The 5 closest chunks are passed to the model as context.

Course data

18 Sigma Web Development videos, from installing VS Code to the CSS box model, split into timestamped chunks and stored in a joblib file that loads when the server starts.

Sources

Each answer lists the video number, title and time range of the passages it was built from, so you can go back and watch that part.

Backend

A Flask server receives your question at the /ask route and returns the answer with its sources.

Answers can still be wrong. Check important facts against the cited video.

Learn from your own course

Scholaris AI is a teaching assistant that answers questions using your academic course materials.

Objective

Give students quick, clear answers from their course content, with a pointer back to where each answer came from.

How it works

  • 1. You ask a question
  • 2. Gemini turns it into an embedding vector
  • 3. The 5 closest course passages are found
  • 4. Gemini writes a short answer from only those passages
  • 5. The video and time range of each passage are shown

Technology

HTML, CSS and JavaScript on the front end. Python and Flask on the back end, with NumPy, pandas and scikit-learn for retrieval. Google Gemini handles embeddings and answers.

Good to know

It only knows the 18 course videos. Unrelated questions get a short reply saying it can only help with course questions. Answers are brief, about 4 to 5 points.
